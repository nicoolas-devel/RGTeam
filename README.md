🌟 Sobre el proyecto
RGTeam es una página web de venta de videojuegos inspirada en plataformas como Steam y Epic Games.

Este proyecto fue desarrollado como práctica de desarrollo web utilizando HTML, CSS y JavaScript.

🚀 Funcionalidades
🛒 Carrito de compras
🔍 Buscador de juegos
🎠 Carrusel interactivo
💻 Diseño moderno gaming
⚠️ Página de Error 404 personalizada
📱 Diseño responsive
🛠️ Tecnologías utilizadas
HTML
CSS
